# تطبيق تنفيذ الطاقة الوطنية

تطبيق الكشف الموقعي لشركة **الطاقة الوطنية للمقاولات العامة** – الحلة، شارع أربعين، قرب حلويات السموأل – 07765656559.

يملأ الموظف بيانات الكشف ويلتقط الصور من داخل التطبيق، ثم يحفظ التقرير بصيغة PDF في مجلد `Download/الطاقة الوطنية` على الهاتف أو يشاركه مباشرة (واتساب، تيليغرام...).

## التنزيل
**[⬇️ تحميل التطبيق (APK)](https://github.com/engsaifhayder-oss/national-energy-POJECT_EXECUTION/releases/latest/download/national-energy.apk)**

## كيف يعمل البناء
- واجهة التطبيق كلها في `index.html`.
- عند كل تعديل يُرفع إلى فرع `main`، يبني GitHub Actions ملف APK موقّع تلقائياً وينشره في صفحة Releases بنفس رابط التحميل أعلاه.
- مشروع أندرويد (WebView) في مجلد `app/`، ويعمل التطبيق بالكامل بدون إنترنت.
