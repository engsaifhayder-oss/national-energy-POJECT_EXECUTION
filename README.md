# تطبيق تنفيذ الطاقة الوطنية

تطبيق تنفيذ المشاريع لشركة **الطاقة الوطنية للمقاولات العامة** – الحلة، شارع أربعين، قرب حلويات السموأل – 07765656559.

يملأ موظف التنفيذ بيانات العمل المنفّذ ويلتقط الصور من داخل التطبيق، ثم يحفظ التقرير بصيغة PDF في مجلد `Download/الطاقة الوطنية - التنفيذ` على الهاتف أو يشاركه مباشرة (واتساب، تيليغرام...).

## كيف يعمل البناء
- واجهة التطبيق كلها في `index.html`.
- عند كل تعديل يُرفع إلى فرع `main`، يبني GitHub Actions ملف APK موقّع تلقائياً وينشره في صفحة Releases بنفس رابط التحميل أعلاه.
- مشروع أندرويد (WebView) في مجلد `app/`، ويعمل التطبيق بالكامل بدون إنترنت.
